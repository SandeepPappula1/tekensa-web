what happens to what you send

kept exactly as sent

The original never changes. What Tekensa reads from it sits beside it, and you can correct any of it; your word is final.

read by rules first, a model second, and it says which

Dates, amounts and page text are read by rules. A model looks inside a photo, a reel or a voice note, and every note it makes is marked as inferred.

delete everything, no copy kept

One thing, or all of it. Anything that looks like a password or a code is never read at all. How Tekensa keeps things.
